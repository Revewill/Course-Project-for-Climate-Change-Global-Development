# Carbon Pricing and Cement Producers’ Pricing and Investment Decisions

本仓库收录《气候变化与全球发展》课程报告《碳价对水泥企业的定价与投资决策的影响——从华新水泥的吨产品毛利谈起》所使用的数据、R 代码、分析结果和论文文件。报告最终版 PDF 和 LaTeX 源文件压缩包均位于 [`paper/`](paper/)。

## 研究内容

报告以华新水泥 2024 年的吨产品毛利为起点，考察与全球 1.5°C 减排路径相匹配的碳价如何影响水泥企业的经营决策。分析将 IPCC 路径中的全球边际减排成本用作假设税率，并设定企业对直接排放全额缴税。

- **碳成本与毛利。** 结合华新集团的水泥销售数据和境内成品水泥直接排放强度，估算售价、销量和生产技术维持原状时的吨毛利，以及使原有毛利降至零的碳价。
- **定价与市场竞争。** 将维持报价、部分转嫁和全额转嫁碳成本时的经营贡献进行比较，测算企业少涨价时需要增加多少销量才能弥补让利，并结合欧洲市场的历史转嫁率讨论这一策略的适用条件。
- **下游采购与减排投资。** 利用公开混凝土配方估算水泥涨价带来的新增采购支出，并以美国能源部的参考工厂为例，在给定碳价下比较不同产量情景中立即改造、等待一年和继续使用原设备的净现值。

## 仓库目录

| 目录 | 内容 |
| --- | --- |
| [`data/`](data/) | R 脚本使用的输入数据，包括碳价情景、水泥排放强度、企业经营数据、市场参数及工程案例数据。 |

## 复现分析

1. 下载或克隆整个仓库，在 R 或 RStudio 中将工作目录设为仓库根目录，使 `data/` 和 `output/` 均可通过相对路径访问。
2. 安装 [`script/`](script/) 中 R 代码开头列出的依赖包，从头运行分析。生成的表格和图片写入 `output/`。
3. 查阅 [`output/article_results.csv`](output/article_results.csv) 可快速核对正文中的主要数值，包括征税后的吨毛利、毛利归零对应的碳价、覆盖可避免成本所需的转嫁率，以及混凝土采购成本增量。

如需编辑报告，解压 `paper/` 中的 LaTeX 项目，以 `main.tex` 为主文件，使用 XeLaTeX 和 BibTeX 编译。仅阅读报告可直接打开同目录下的最终版 PDF。

## 数据口径

碳价按每吨二氧化碳（t CO₂）计价，水泥售价、成本和毛利按每吨售出水泥计算。华新案例以境内直接排放强度近似集团产品强度；美国参考工厂的投资参数仅用于改造情景测算。跨地区比较时，各项金额的币种、价格基年及单位见对应图表。
